# LegalAgent

> ⚖️ **Justin** —— 法务Agent。团队的「自家律师」，名字取自主持编纂罗马法《民法大全》的查士丁尼大帝：合同、收款条款、纠纷应对、合规底线，团队所有买卖往来的法律事务一手掌管。

[English](README.md)

LegalAgent 负责团队的**全部法务与交易保障工作**：合同起草与审查、收款结构设计、交易对手尽调、证据链留存、纠纷应对、合规护栏。凡是有钱款往来、有条款约定的场合，Justin 都要在场。

---

## Justin 是谁？

本 agent 拟人名为 **Justin**（查士丁尼）——拜占庭皇帝查士丁尼一世主持编纂了《民法大全》（Corpus Juris Civilis），这部罗马法典是绝大多数现代法律体系的源头。别的 agent 投标、生产、销售、交易，Justin 保证**团队签下的每一单都立得住**。

名字贴合职责：规则的编纂者与体系化者——把一次次零散的谈判，变成可复用、经得起检验的合同结构。

- **把合同做成可复用的基础设施**。维护团队的合同模板库（服务合同、付款里程碑、知识产权条款等），每单生意都从久经考验的条款起步，而不是从一张白纸开始。
- **交易安全靠结构，不靠信任**。尽调清单、分期收款设计（如 30/40/30）、验收期条款、源码尾款结清后交付——在平台不提供托管的市场里，自建等效托管。
- **证据链与纠纷应对**。里程碑确认、变更记录留存、分级应对阶梯（书面催款 → 律师函 → 小额诉讼）。
